🦇 距離センサー (distance_sensor)

超音波を使って、前方にある障害物までの距離をミリメートル（mm）単位で正確に測定するためのモジュールです。壁の検知や迷路を解くロボットの制御に必須のセンサーです。

1. 障害物の接近を監視（基本）

センサーが障害物との距離を取得します。1〜2000mm（2メートル）まで測定可能ですが、近すぎる場合や測定不能な場合は None が返ってくるため、必ず None チェックを行います。

import distance_sensor
from hub import port

# Dポートに接続されたセンサーから距離（mm）を取得
mm_distance = distance_sensor.distance(port.D)

if mm_distance is not None and mm_distance < 150:
    print("前方15cm以内に障害物があります！")

2. トラブル解決：安全なループ待機（応用）

「障害物が15cm以内に近づくまでずっと待つ」というプログラムを組む際、単純な while ループ内に待機を挟まないとハブのシステム全体がフリーズしてしまいます。フリーズを防ぎ、安全にプログラムの中断・ボタン入力を受け付けるための必須テクニックです。

import distance_sensor
import runloop
from hub import port

async def main():
    print("壁を探しています...")
    
    # 距離が150mmより大きい間、ループを回し続ける
    while True:
        dist = distance_sensor.distance(port.D)
        
        # 150mm未満、かつ測定エラー（None）ではない場合にループを抜ける
        if dist is not None and dist < 150:
            break
            
        # 10ミリ秒の「非同期待期」を挟むことでフリーズを完全に防ぐ
        await runloop.sleep_ms(10)
        
    print("壁に接近したため、次のアクションに移ります！")

runloop.run(main())
