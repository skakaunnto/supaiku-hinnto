🟣 非同期の基本 (async / await)

SPIKE App 3のPython環境では、モーターの稼働待ちや時間待ちの処理に「非同期処理（Asynchronous）」が採用されています。時間を有効に使い、フリーズを防ぐための最重要の基本ルールを解説します。

1. async と await の基本ルール

SPIKEのプログラムを動かすメインの関数には、頭に必ず async を付けます。また、時間を待つ関数（sleep_msなど）を呼び出すときは、その前に必ず await を記述する必要があります。

import runloop

# メイン関数を非同期（async）として定義する
async def main():
    print("プログラムスタート")
    
    # awaitを付けることで、指定した時間（1000ミリ秒＝1秒）非同期で待機します
    # この待機中も、ハブのシステムは他の処理を実行することができます
    await runloop.sleep_ms(1000)
    
    print("1秒経ちました。終了します。")

# 実行ループに関数を登録して起動する
runloop.run(main())
