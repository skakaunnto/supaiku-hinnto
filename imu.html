🧭 内蔵ジャイロセンサー (imu)

SPIKEプライムのハブ内部に組み込まれている6軸慣性計測装置（IMU）です。ロボットが向いている水平な角度（ヨー角）や、前後左右の傾きをリアルタイムに検知して、ブレのない超高精度な走行を実現します。

1. 旋回角度の取得（基本の注意点）

ハブが回転した角度（方位）を取得します。SPIKE App 3の仕様として、ジャイロセンサーの戻り値は「実際の度数の10倍」の整数で返ってきます（例：90度回転したときの値は 900 になります）。プログラム内で扱う際は注意してください。

import imu

# 現在のハブの回転角度を取得する
raw_angle = imu.rotation()

# 10で割ることで、見慣れた「〇度」の数値に変換できます
yaw_angle = raw_angle / 10
print("現在の向き: " + str(yaw_angle) + "度")

2. 実践応用：ジャイロセンサーでピタッと90度曲がる決定版

ロボットのモーター駆動だけだと、タイヤのスリップやバッテリー残量で回転がズレてしまいます。ジャイロの値をリアルタイムで監視しながらスピン旋回させ、90度（900）に達した瞬間にモーターをガチッと固定停止（HOLD）させる最高峰の走行テクニックです。

import motor_pair
import imu
from hub import port
import runloop
import motor

async def main():
    # 左右の走行用モーターを設定
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.B)
    
    # 1. いま向いている向きを「0度」として基準をリセット
    imu.reset_yaw(0)
    await runloop.sleep_ms(100) # リセット処理がハブ内で安定するまで少し待つ
    
    # 2. 右にスピン旋回をスタート（ずっと回すモード）
    motor_pair.move(motor_pair.PAIR_1, steering=100, velocity=200)
    
    # 3. ジャイロの角度が「90度（数値として900）」になるまで非同期ループで監視
    while imu.rotation() < 900:
        await runloop.sleep_ms(5) # 5ミリ秒ごとに超高速でチェック
        
    # 4. 90度になった瞬間にガチッと電子ブレーキをかけて停止
    motor_pair.stop(motor_pair.PAIR_1, stop=motor.HOLD)
    print("正確な90度旋回が完了しました！")

runloop.run(main())
