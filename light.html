💡 ライトマトリクス (5x5画面)

SPIKEハブの表面にある5x5マトリクスLEDの表示をコントロールするモジュールです。現在のロボットの状態を表示させたり、デバッグメッセージをスクロール表示するのに役立ちます。

1. 文字列のスクロール表示

ハブの画面にアルファベットのテキストを1文字ずつ左へ流れるように表示させます。プログラムのスタート合図（GOなど）によく使われます。

import hub
import runloop

async def main():
    # ハブの画面に「GO」という文字をスクロール表示する（表示完了を待つ）
    await hub.light_matrix.write("GO")

runloop.run(main())

2. 公式組み込みイメージの表示

配列の定義を使わずに、SPIKEシステム内にあらかじめ登録されている「笑顔（IMAGE_HAPPY）」や「ハート」などのアイコンをパッと表示させることができます。

import hub

# 画面にビルトインの笑顔マーク（HAPPY）を表示する
hub.light_matrix.show(hub.light_matrix.IMAGE_HAPPY)
