🎨 カラーセンサー (color_sensor)

SPIKEのカラーセンサーは、周囲にある物体の「色」を識別したり、床面から反射して返ってくる「光の強さ（反射光）」を測定するための非常に強力なモジュールです。

1. 基本的な色の検知

センサーの前に置かれた色（赤、青、緑、黄など）を判定します。特定の色のブロックを検知してロボットを停止させるプログラムなどに使用します。

import color_sensor
from hub import port

# Cポートに接続されたセンサーが検知している色を取得
# 戻り値: color_sensor.RED, color_sensor.BLUE, color_sensor.GREEN, None（色なし）など
detected_color = color_sensor.color(port.C)

if detected_color == color_sensor.RED:
    print("赤色を検知しました！")

2. 非同期ループでの常時監視

while True: を使ってロボットが走っている間、常に色が変わったかどうかをチェックし続ける非同期プログラムです。ハブがフリーズしないよう、必ず runloop.sleep_ms を挟みます。

import color_sensor
import runloop
from hub import port

async def main():
    print("色の監視を開始します...")
    while True:
        color = color_sensor.color(port.C)
        if color == color_sensor.RED:
            print("赤を検知！")
        
        # 10ミリ秒休憩（ハブのフリーズ防止）
        await runloop.sleep_ms(10)

runloop.run(main())

3. 応用テクニック：ライントレース（2値制御）

地面に書かれた黒い線の「境界線」をなぞるように走るプログラムです。反射光の強さ（0〜100）を取得し、数値が小さければ黒、大きければ白と判定して左右のモーターを微調整しながら進みます。

import motor_pair
import color_sensor
from hub import port
import runloop

async def main():
    # AとBのモーターをペアリング
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.B)
    
    # 5秒間（10ミリ秒 × 500回ループ）走る例
    for _ in range(500): 
        brightness = color_sensor.reflection(port.C)
        
        if brightness < 40: # 黒の上なら
            # 右に曲がって白の側へ出る
            motor_pair.move(motor_pair.PAIR_1, steering=30, velocity=300)
        else: # 白の上なら
            # 左に曲がって黒の側へ入る
            motor_pair.move(motor_pair.PAIR_1, steering=-30, velocity=300)
            
        await runloop.sleep_ms(10) # 10ミリ秒ごとにセンサーをチェック
        
    # 時間が来たらモーターを完全に停止
    motor_pair.stop(motor_pair.PAIR_1)

runloop.run(main())
