🟢 同時並行処理 (create_task)

「ロボットを走らせながら、スピーカーから音を鳴らし、同時に画面のライトを点滅させる」といった、複数の仕事を完全に同時に実行させるための高度なテクニックです。

1. 複数のタスクを同時に起動する

runloop.create_task() を使用すると、バックグラウンドで別の関数を同時に走らせることができます。メインの処理を止めずに、別のアクションを並行させたいときに非常に役立ちます。

import runloop
import sound
import hub

# バックグラウンドタスク1: 1秒ごとにBEEP音を鳴らし続ける
async def task_sound():
    while True:
        await sound.play_beep(60, 200)
        await runloop.sleep_ms(1000)

# バックグラウンドタスク2: 0.5秒ごとに画面に「!」を出し続ける
async def task_light():
    while True:
        await hub.light_matrix.write("!")
        await runloop.sleep_ms(500)

async def main():
    # 2つの独立した関数を、並行タスクとして同時に登録・起動
    runloop.create_task(task_sound())
    runloop.create_task(task_light())
    
    # メインループ：これ自体も動かし続ける必要があります
    print("同時並行タスクが起動しました")
    while True:
        await runloop.sleep_ms(10)

runloop.run(main())
