🟠 無限ループとフリーズ防止

SPIKEのPythonプログラムにおいて、最も遭遇しやすい「ハブのフリーズトラブル」の原因と、それを解決するための絶対ルールを解説します。

1. フリーズの原因と正しい対策

非同期環境における while True:（無限ループ）の中に、await を使った待機処理が1つも含まれていない場合、プログラムがハブの処理能力を100%占有してしまい、ハブが完全にフリーズ（ボタン操作すら受け付けない状態）します。フリーズを防ぐには、必ずループ内にわずかでも休憩を挟んでください。

import runloop

async def main():
    print("ループ処理を開始します（フリーズ対策済）")
    
    while True:
        # ここに常時実行したい処理を書きます
        # 例: センサー値の読み込みなど
        
        # 【重要】わずか1ミリ秒でも await で休憩を入れることで、
        # ハブのシステムに制御権が戻り、フリーズを完全に防止できます。
        await runloop.sleep_ms(1)

runloop.run(main())
