🖲️ フォースセンサー (force_sensor)

ボタンが「押されたか・離されたか」というタッチスイッチとしての検知機能に加え、先端にどれくらいの力が加わっているかをニュートン（N）単位で精密に測定できる圧力センサーです。

1. ボタンの押し込み状態を調べる（基本）

現在ボタンが物理的にカチッと押されているかどうかを二択（True または False）で判定します。バンパースイッチ（壁にぶつかったらバックする等）のプログラムに最適です。

import force_sensor
from hub import port

# Eポートに接続されたセンサーが押されているか判定
if force_sensor.pressed(port.E):
    print("タッチスイッチが押されています！")

2. スイッチが押されるのをループで待つ（非同期）

ユーザーがロボットのボタンを押すまでプログラムを待機（ポーズ）させます。非同期ループを回し、ボタンが検出された瞬間にトリガーを引きます。

import force_sensor
import runloop
from hub import port

async def main():
    print("スイッチが押されるのを待っています...")
    
    # スイッチが押されていない（False）の間、ループを繰り返す
    while not force_sensor.pressed(port.E):
        # 10ミリ秒ごとにチェック（フリーズ防止）
        await runloop.sleep_ms(10)
        
    print("カチッ！スイッチが押されたのでロボットを起動します！")

runloop.run(main())
